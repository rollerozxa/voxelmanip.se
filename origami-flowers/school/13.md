The **(PGM Bookie)** screen can be accessed from the **(Chatterbox)** shortcuts and the **(Menu)** button found on the main flower display.

As the name suggests, the **(PGM Bookie)** lets you bet on the results of various events. The **(PGM Bookie)** screen offers ***tickets*** available for purchase using PGM when a wager is open.

Each ticket describes the **winning requirement**, **cost in PGM**, and **payout in PGM**. The **payout** only occurs if the ticket meets the **winning requirements**.

For example: If a ticket is available for a boxing match and is described as...

> **Boxing: Timothy Bradley vs. Manny Pacquiao: Bradley Wins**
> - - -
> I own: (**14**) tickets \
> Possible payout: **406** PGM \
> Closes (**229**hr, **23**min, **36*s)
> - - -
> Ticket Cost **10 PGM** \
> Ticket Payout: **29 PGM**

This means...

- The ticket only pays out if Bradley wins the boxing match.
- I have already purchased 14 tickets
- **IF** and only if the ticket wins: I will receive 406 **PGM**
- I have 229hr, 23min and 36sec remaining to buy more tickets. When the time runs out, the option to buy more of this ticket will go away.
- Each ticket costs **10 PGM**. So if I want 3 more tickets, that will cost **3 x 10 = 30 PGM**
- The payout if the ticket wins is **29 PGM**. So if it wins, I will receive **29 PGM** for every ticket I am holding: **29 x 14 = 406 PGM**

The **(PGM Bookie)** screen only displays to you tickets that are currently **available** for purchase, or tickets that you already own. The tickets that you already own remain visible in the (PGM Bookie) screen until the ticket is **finalized**.

Tickets usually **stop being available** for purchase just **before an event starts**, and are **finalized** some time shortly **after the event ends**. Do not be surprised if a ticket you own is not finalized until the next day, especially if it ends late in the night. A real person has to validate the results and hit a button.

If a ticket is **cancelled** because the event it relies on is altered or cancelled, you will receive a refund of all of the **PGM** you spent buying the tickets.

**\*IMPORTANT\***: Read the description in detail for every ticket you are interested in. Sometimes tickets will have a performance based payout. For example, during every UFC event, we have a ticket like this...

> **UFC Fight Night 39 MMA fantasy pool event: Payout is determined by Adams rank in the MMA Pool: Every player that scores better than Adam increases the payout by 1: So if Adam is ranked 6th, the payout will be 5 PGM. If Adam is ranked 20th, the payout is 19, etc.**

So if Adam fimishes with a rank of 3rd, you will still recerve a **winning** ticket message, although the winning amount will only be **2 PGM** in that case which is less than you paid. If Adam ranks 25th, you will win 24 PGM for every ticket owned.

One last tidbit of information: **Bookie tickets** are often created because of requests from players. If you follow a certain sport, or have an interesting idea for a ticket, talk about it in **(Chatterbox)**!
